How this should work

Quercus is Canvas. Students get the API for free: you mint a personal access token while signed in, then this app calls JSON endpoints as you. No developer key, no instructor role. If you cannot open a file in the browser, the API cannot download it either.

  1. Sign in at q.utoronto.ca.
  2. Open Account → Settings → New Access Token.
  3. Give it a purpose like “personal course archive on my laptop” and paste it below. The token never leaves this machine.

This lists current and concluded enrolments, then copies Files-tab PDFs plus files attached to modules and assignments. Locked or date-restricted courses are skipped. Quiz questions are not fetched. Do not share copyrighted course packs.
